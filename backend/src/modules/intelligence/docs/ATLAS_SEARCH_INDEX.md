# MongoDB Atlas Vector Search Configuration

To enable vector similarity searches (Semantic Search) over the `KnowledgeRecord` collection, you must create a dedicated **Atlas Vector Search Index** via the MongoDB Atlas UI or Atlas CLI.

## Index Configuration

- **Database**: `orivox_db` (or your configured DB name)
- **Collection**: `knowledgerecords`
- **Index Name**: `vector_index` (or `default`)

### JSON Definition

```json
{
  "fields": [
    {
      "numDimensions": 1024,
      "path": "embedding",
      "similarity": "cosine",
      "type": "vector"
    },
    {
      "path": "organizationId",
      "type": "filter"
    },
    {
      "path": "projectId",
      "type": "filter"
    },
    {
      "path": "tags",
      "type": "filter"
    }
  ]
}
```

### Configuration Details
1. **Dimensions**: Set to `1024` to match the exact dimension size generated by `mistral-embed`.
2. **Similarity Metric**: We utilize `cosine` similarity, which is standard for embedding comparison evaluating the angle between vectors (semantic meaning) rather than strict magnitude.
3. **Filters**: We explicitly index `organizationId`, `projectId`, and `tags` as filter fields. This is absolutely critical to guarantee robust multi-tenant data isolation before performing nearest-neighbor (k-NN) queries.
